# F4 — Busca, referências, favoritos, lixeira e validação do MVP

Status: CORRIGIDO E VERIFICADO

## Objetivo
Validar o estado real do repositório para a etapa F4, confirmar o que já estava implementado e concluir o restante do escopo de busca, referências, favoritos, lixeira e validação do MVP dentro do que a arquitetura atual admite, sem avançar para F5.

## Requisitos aplicáveis
- RF-013: relacionar páginas por referência interna.
- RF-015: pesquisar toda a biblioteca.
- RF-016: favoritar e retomar páginas.
- RF-017: excluir com lixeira e restaurar.
- Dependências: F1–F3 concluídas; persistência de áreas, anexos e conteúdo já em vigor.

## Estado real do código
- O frontend já tinha uma busca local simples na lista da estante, mas ela não consultava o servidor nem cobria a biblioteca inteira.
- O backend ainda não expunha API de busca global, nem campos de favorito/lixeira; as páginas eram apenas listas ativas, sem marcação de favorito e sem soft-delete.
- A arquitetura atual preserva `Area` como entidade central e o conteúdo em JSON Tiptap; isso é compatível com a etapa F4 sem introduzir um modelo paralelo.
- O que foi concluído nesta etapa foi a base funcional para identificação, busca global, favoritos e lixeira, sem expandir para as visões de F5 nem criar um sistema de referência interna complexo fora do modelo existente.

## Decisões e ajustes
1. Mantivemos `Area` como fonte de verdade e adicionamos suporte de dados aditivos (`isFavorite`, `lastOpenedAt`, `deletedAt`) para preservar compatibilidade com o modelo atual.
2. A busca global foi implementada no backend como consulta ao conjunto de áreas do usuário, excluindo deletadas e consultando nome, categoria e conteúdo JSON em texto simples.
3. A lixeira foi tratada como soft-delete: a área continua persistida e oculta das consultas ativas, com restauração explícita.
4. A ação de favorito foi implementada como toggle no backend e no frontend, sem duplicar registros nem criar dados paralelos.
5. Não foi antecipado F5; a etapa ficou restrita ao escopo de F4 e ao comportamento MVP de recuperação e organização.
